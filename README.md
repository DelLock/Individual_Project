## 📋 Описание

**Fast4Sale** — это полнофункциональное десктоп-приложение для рынка недвижимости, разработанное на C# и WPF. Приложение позволяет пользователям создавать аккаунты, публиковать объявления о продаже/аренде недвижимости, искать объекты по различным критериям и связываться с продавцами напрямую.

### Ключевые особенности:
- 🎨 **Современный темный интерфейс** с акцентными цветами
- 📱 **Простая и интуитивная навигация**
- 💾 **Встроенная база данных SQLite** (не требует сервера)
- 🔍 **Мощная система поиска и фильтрации**
- 📸 **Поддержка загрузки фотографий** объектов
- 🔐 **Система авторизации и регистрации**

## 🚀 Функции

### Для всех пользователей:
- 🔍 **Просмотр объявлений** с фильтрацией по:
  - Типу недвижимости (квартира/дом)
  - Ценовому диапазону
  - Количеству комнат
  - Местоположению
- 📄 **Детальный просмотр** объявлений с фотографиями
- 📞 **Контактные данные** продавцов (email, телефон)

### Для зарегистрированных пользователей:
- 👤 **Личный кабинет** с управлением профилем
- ➕ **Создание новых объявлений** о недвижимости
- ✏️ **Редактирование и удаление** своих объявлений
- 📊 **Просмотр статистики** своих публикаций


### Требования к системе:
- **ОС:** Windows 7/8/10/11
- **.NET Framework:** 4.7.2 или выше
- **Память:** 2 ГБ ОЗУ (минимум)
- **Диск:** 100 МБ свободного места
